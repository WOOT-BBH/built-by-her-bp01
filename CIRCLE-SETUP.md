# Add the lesson to Circle

The published lesson URL is:

`https://woot-bbh.github.io/built-by-her-bp01/`

```html
<iframe
  src="https://woot-bbh.github.io/built-by-her-bp01/"
  title="Built By Her — Business Planning Lesson 1"
  style="width:100%;height:900px;border:0;border-radius:12px;"
  loading="lazy"
  allow="clipboard-write"
></iframe>
```

In Circle, edit the course lesson and add an embed or custom HTML block. Paste the iframe code, then preview on desktop and mobile. If the lesson feels cramped, increase `height` from `900px`; the course itself scrolls inside the frame.

If your Circle plan or editor does not permit a custom iframe, paste the GitHub Pages URL as an external link instead.
