# Built By Her design system

Built By Her brings practical business guidance and trusted expertise together inside the Womeniverse™. This folder is the brand brief for Claude Design and future Built By Her work. The [BP-01 lesson](../README.md) is a product example, with some typography choices that differ from the brand guide.

## Source order

1. Supplied final logo artwork and *Built By Her — Brand Quick Start Guide* govern logo use. Use the original artwork unchanged.
2. *Built By Her — Tone of Voice and Content Guide* governs writing.
3. The [BP-01 lesson](../index.html) and [styles](../styles.css) show one implemented course experience; its layout and accessibility patterns are useful references.
4. The tokens in [tokens.css](tokens.css) record the current BP-01 web palette and suggested interface roles. Treat them as implementation values, and compare against the final artwork before producing new print assets.

## Identity

- Use the full name **Built By Her** externally. BBH is internal shorthand.
- Built By Her is the practical business guidance layer **inside the Womeniverse™**. The Womeniverse™ is the wider membership and trusted whole-life resource.
- Logo: use the supplied horizontal master for general use, stacked lock-up for square or portrait compositions, and the supplied H master for monograms. Never redraw, trace, recolour, reshape, reweave or add effects to the H. The H-only scalable master is an SVG; if it has not been supplied to Claude, ask for that exact file rather than reconstructing it.
- Use a generous clear area around the logo. On dark, coloured or photographic backgrounds use the supplied white holding-card asset.
- Navy leads, teal connects, orange marks action, and purple adds support and perspective. Use white or a pale neutral for most backgrounds.
- Brand typography: Montserrat for working copy; DM Serif Display sparingly for editorial emphasis. These font files are **not** included in this repository. Use licensed/available fonts or ask for the files. The BP-01 web lesson currently uses system sans and Georgia and should not be mistaken for the brand font specification.
- Imagery should show women thinking, building, deciding and doing. Avoid staged boardrooms and clichés.

## Interface patterns

- A clear page title, a brief outcome, and one realistic next action.
- White reading panels on a pale background; spacious margins and readable line lengths.
- Distinguish content, activities, optional guidance and export actions. The existing lesson demonstrates responsive cards, labelled fields, expandable guidance and a text-based PDF export.
- Teal for navigation and progress cues; orange for the primary action; purple for supporting emphasis. Keep text contrast strong and visible keyboard focus.
- On narrow screens, stack columns and keep body text readable. Respect reduced-motion preferences.
- Do not imply that a learner's answers are saved to an account: BP-01 uses temporary browser storage and requires PDF export to keep a copy.
